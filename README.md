# Screen Time Tracker

## Project Overview
Screen Time Tracker is a web-based application designed to help users monitor and manage their daily screen time. It helps users understand their digital habits, track usage activities, and improve productivity through better time management.

## Features
- Track daily screen time.
- Monitor application usage activities.
- Manage and view activity details.
- Set daily screen time goals.
- Simple and user-friendly interface.
- Store data using browser Local Storage.

## Technologies Used
- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript – Application functionality.
- Local Storage – Store user data in the browser.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the Screen Time Tracker.

## Purpose
The main purpose of this project is to encourage healthy digital habits by helping users understand and manage their screen time effectively.
